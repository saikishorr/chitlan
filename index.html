Everything you need

One place for real-time collaboration.

ChitLAN brings communication and collaboration tools together in a lightweight browser-based experience.

💬

Real-Time Workspace Chat

Communicate instantly with group messaging, typing indicators, timestamps, notifications, and persistent chat history.

📹

Camera Video Meetings

Join live multi-peer camera video meetings with participant grid tiles, name badges, and camera/microphone controls.

🖥️

Screen Share Takeover

Share desktop or app windows with conflict takeover management and active sharer title badges in sidebar & theater views.

🔀

Smart Auto-Redirection

Intelligent P2P redirection automatically connects joiners of non-host peers to the main Host room with 10-member capacity limits.

👑

Host Control Suite

Exclusive Host controls to kick/remove unwanted participants, mute all microphones, and lock workspace rooms.

😀

Emoji & GIF Search Engine

WhatsApp-style keyword emoji picker with cursor insertion and searchable GIF lightbox modal for P2P image broadcasting.

📁

Advanced File Sharing

Send files straight to the room. Each person accepts or declines first. Files up to 64 MB work in any browser; larger files need a browser with local file storage (Chrome, Edge or Firefox) and enough free space. Live progress, speed and image previews.

🌙

Modern Glassmorphism

Responsive dark mode, high-contrast color tokens, PWA support, and a sleek UI designed for seamless P2P collaboration.
